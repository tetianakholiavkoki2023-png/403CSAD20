Варіант 20: протокол I2C, мова реалізації Verilog

## Структура проєкту

- `i2c_tx.v` — синтезований модуль передавання Master: START, 7-бітна адреса + R/W, 8-бітні дані, ACK/NACK і STOP.
- `i2c_rx.v` — модуль приймача: режим Master Receiver для читання одного байта та режим Slave Receiver з параметром адреси.
- `i2c_master.v` — верхній Master-контролер, який об'єднує Tx і Rx для виконання однобайтових операцій запису або читання.

Усі сигнали шини є open-drain керуваннями: `0` означає активно опустити лінію, `1` означає відпустити лінію. Зовнішні рівні `SCL` та `SDA` передаються окремо через порти `*_i` та `*_o`. Для реальної шини необхідно додати зовнішні підтяжки до живлення і такі тристейтові прив'язки:

```verilog
assign sda = sda_o ? 1'bz : 1'b0;
assign scl = scl_o ? 1'bz : 1'b0;
```

## Параметр тактового дільника

Модулі мають параметр `CLK_DIV`, який задає повну кількість тактів системного `clk` для одного періоду `SCL`:

```verilog
i2c_master #(.CLK_DIV(500)) master_inst (...);
```

Наприклад, для системного тактування 50 МГц та I2C 100 кГц:

```text
50 000 000 / 100 000 = 500 системних тактів на період SCL
CLK_DIV = 500
```

`CLK_DIV` має бути парним і не меншим за 4.

## Інтерфейс Master

- `start_i=1` запускає операцію;
- `rw_i=0` передає `data_i[7:0]` після адресного байта;
- `rw_i=1` читає один байт у `data_o[7:0]`;
- `address_i[6:0]` є 7-бітною адресою пристрою;
- `done_o` підтверджує завершення;
- `nack_o` сигналізує NACK або відсутність ACK;
- `data_valid_o` одним тактом підтверджує дійсність `data_o`.

Адресний байт має формат:

```text
{address_i, rw_i}
```

де молодший біт має значення R/W: `0` для запису і `1` для читання.

## Синхронізація SDA/SCL

Дані змінюються лише при опущеному SCL. Сканування SDA здійснюється на високому рівні SCL. START визначається зміною SDA 1→0 при SCL=1, STOP — 0→1 при SCL=1. При Master Receiver після останнього прийнятого байта модуль видає NACK і формує STOP.

## Testbench

`i2c_tb.v` перевіряє:

- Standalone Tx у парі зі Standalone Rx Slave;
- запис даних через `i2c_master` з ACK емулятора Slave;
- читання даних через `i2c_master` з ACK адреси та поточним байтом `0xC3`;
- останній байт Master Receiver супроводжується NACK;
- стан FSM Tx, Rx та Master доступний у ієрархії `dut_tx`, `dut_rx_slave`, `dut_master`.

Запуск і дамп VCD:

```sh
iverilog -g2001 -o i2c_tb.vvp i2c_tx.v i2c_rx.v i2c_master.v i2c_tb.v
vvp i2c_tb.vvp
```

Результат симуляції відкривається у GTKWave:

```sh
gtkwave i2c_wave.vcd
```

У консолі виводяться часові мітки запуску тестів, RX-байти, ACK/NACK і стан виконання; у дамп потрапляють `clk`, `rst_n`, `SCL`, `SDA`, Busy/Done, дані та стан FSM.
